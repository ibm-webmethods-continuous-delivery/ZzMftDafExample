# ZzDafEmptyPackage

This is a template repository providing the minimum `manifest.v3` file to qualify a folder as an Integration Server package.

The files `README.md` and `LICENSE` are provided for GitHub presentation and corporation licensing policies.

**Guildeline**:

When developing packages for production load consider removing these files from here and if required for legal purposes, store them in a separate folder. This saves  memory at runtime.
